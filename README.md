PhotoScope
link -https://alikz0.github.io/photoScope/

Сайт на HTML, CSS и JavaScript для просмотра метаданных фотографий.
Показывает сведения, которые сохранились в выбранном файле: устройство,
дату съёмки, координаты GPS, настройки камеры и технические теги.

Фотографии обрабатываются в браузере и не отправляются на сервер.
Для работы приложения не нужны ключи API, база данных или установка npm-пакетов.

Открыть онлайн-версию: https://photo-inspector-alik.zalinov96.chatgpt.site/.
Текущая опубликованная версия доступна владельцу через его аккаунт ChatGPT.
Для локального запуска вход в аккаунт не требуется.

Возможности

- Выбор файла, перетаскивание в область загрузки и вставка изображения из буфера обмена.
- Производитель и модель камеры или телефона; объектив и параметры съёмки.
- Дата и время съёмки, часовой пояс, даты оцифровки и обработки, если они записаны.
- Координаты GPS, высота и переход на карту OpenStreetMap.
- Размер файла, разрешение, формат, тип MIME, переданный браузером, и хеш SHA-256.
- Просмотр поддерживаемых EXIF, XMP, IPTC, ICC, JFIF, PNG, MakerNotes и других тегов.
- Поиск по названию, значению и русской подписи; фильтрация по группам.
- Просмотр исходных значений и выгрузка полного результата разбора в JSON.
- Адаптивный интерфейс и встроенный пример с искусственными метаданными.

Быстрый запуск

Одним HTML-файлом

Скачайте PhotoScope.html и откройте его в браузере. В исходниках этот файл
находится в папке dist/. Внутри уже есть стили, JavaScript, парсер метаданных
и демонстрационное изображение. Для анализа фотографий интернет не нужен.

Если приложение для просмотра файлов не запускает JavaScript, откройте файл
в браузере или воспользуйтесь онлайн-версией.

Из исходников

Можно открыть dist/index.html напрямую. Для чтения в фоновом потоке
запустите статический сервер. Из корня проекта выполните:

python3 -m http.server 8080 --bind 127.0.0.1 --directory dist

Откройте http://127.0.0.1:8080. Для остановки сервера нажмите Ctrl+C.
Команда требует Python 3; установка зависимостей и сборка проекта не нужны.

При запуске обычной версии через HTTP(S) метаданные читаются в Web Worker.
Через file:// и в автономном PhotoScope.html используется основной поток
браузера. Большие файлы в таком режиме могут временно замедлить интерфейс.

Как пользоваться

1. Нажмите «Выбрать фотографию» или перетащите файл в область загрузки.
2. По возможности выбирайте оригинал через «Файлы». Пересылка в мессенджере,
   скриншот или экспорт из галереи могут удалить часть метаданных.
3. Посмотрите карточки устройства, даты, координат и разрешения.
4. Для подробностей используйте раздел «Все доступные теги», поиск и фильтры.
5. Нажмите «Скачать JSON», чтобы сохранить результат, или «Открыть на карте»,
   чтобы посмотреть координаты.
6. Кнопка с крестиком рядом с именем фотографии очищает текущий результат.

Кнопка «Посмотреть тестовый пример» загружает нарисованную иллюстрацию.
Указанные в ней iPhone, дата, настройки камеры и GPS заданы для демонстрации
и не описывают реальную съёмку.

Форматы и ограничения

Поддерживаются JPEG/JPG, PNG, TIFF, HEIC/HEIF, WebP, GIF, AVIF и JPEG XL.
Максимальный размер файла — 100 МиБ (104 857 600 байт).
Видео и RAW-форматы не заявлены как поддерживаемые.

Доступность сведений зависит от содержимого файла и возможностей ExifReader.
«Все доступные теги» означает все теги, которые удалось прочитать встроенным
парсером. Некоторые закрытые данные производителя и нестандартные блоки
могут остаться нерасшифрованными.

Браузер может прочитать метаданные HEIC или TIFF, даже если не умеет показать
само изображение. Предпросмотр и чтение метаданных — отдельные операции.
Распаковка сжатых метаданных PNG и JPEG XL зависит от возможностей браузера.

Если сведений нет, приложение показывает это явно. Удалённые из файла данные
не восстанавливаются. Место, дата и модель устройства не угадываются по картинке.

Приватность и достоверность

Выбранный файл и результат разбора находятся в памяти вкладки. Приложение
не отправляет их на сервер, не использует аналитику или внешние сервисы
распознавания. Парсеры и стили включены локально; текущую геолокацию устройства
сайт не запрашивает. Вход через ChatGPT защищает доступ к опубликованному сайту,
а обработка фотографий остаётся в браузере.

Карта открывается только после нажатия на ссылку. В этот момент OpenStreetMap
получает координаты из файла. Экспортированный JSON тоже может содержать GPS,
автора и другие сведения, найденные в фотографии.

Метаданные можно изменить. Они не доказывают подлинность, место или дату съёмки.
Если часовой пояс не записан, приложение не подставляет пояс устройства.
Поле «Изменён (по браузеру)» относится к файлу и не заменяет дату съёмки.
SHA-256 позволяет сравнивать содержимое файлов, но не подтверждает их происхождение.

Изменение кода

Редактируйте dist/index.html, dist/styles.css, dist/app.js или
dist/metadata-worker.js в зависимости от задачи. Русские подписи тегов
находятся в объекте LABELS внутри dist/app.js.

После изменения интерфейса, стилей или основного JavaScript пересоздайте
автономную версию из корня проекта:

python3 scripts/export-standalone.py

Скрипт создаёт dist/PhotoScope.html и пересчитывает хеши встроенных скриптов
и стилей для Content Security Policy. Прямое редактирование встроенного кода
в готовом HTML без обновления этих хешей может заблокировать его выполнение.

Развёртывание

Разместите всё содержимое dist/ в каталоге сайта на статическом хостинге.
Файл index.html должен находиться в корне этого каталога. Сохраните имена
и расположение остальных файлов, включая папку vendor/.

Сборочная команда не требуется; каталог публикации — dist.
Приложение не требует серверного кода и переменных окружения.
Доступ к сайту на собственном хостинге определяется настройками этого хостинга.

Второй вариант — разместить только PhotoScope.html и открывать его по прямому
адресу. Для анализа файлов эта версия самостоятельна.

Зависимости и проверка

Зависимость — Версия — Лицензия — Назначение
ExifReader — 4.54.0 — MPL-2.0 — Чтение метаданных изображений
@xmldom/xmldom — 0.9.12 — MIT — Разбор XMP в Web Worker

Исходный код библиотек:
ExifReader: https://github.com/mattiasw/ExifReader и
xmldom: https://github.com/xmldom/xmldom.
Тексты лицензий и сведения о локальных копиях находятся в dist/vendor/.

В Chrome проверены EXIF и GPS, отсутствие метаданных, XMP, сжатый текст PNG,
поиск, экспорт JSON, очистка результата и автономный HTML.
Компоновка проверена на ширине 390 px. Проверка на физическом iPhone
и проверка всех вариантов HEIC не проводились. Подробности — в VALIDATION.md.
